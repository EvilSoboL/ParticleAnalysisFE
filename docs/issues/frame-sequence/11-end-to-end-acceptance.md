## План реализации

1. Выполнить итоговую проверку интеграции; добавлять только недостающие проверки, не дублировать тесты предыдущих issues.
2. Синтетический набор: последовательные кадры с тёмными объектами на светлом фоне и известным смещением. Проверить пары, ориентацию, PTV и скорость при заданном масштабе/dt; размеры частиц и параметры сопоставления подобрать для однозначного результата.
3. Пройти GUI-сценарий на C:/Users/Mark/Desktop/Серии Кадров/series_20260921_134221_206068088/frames, если каталог доступен. Вывод — в новый отдельный каталог вне frames. Оригиналы и config.json не изменять. Если каталога нет, явно отметить это и использовать синтетический набор.
4. Для реальной серии подобрать порог и пределы площади по выделению частиц; не обещать точного совпадения с 8 м/с, это распределение и есть шум/размытие. Проверить, что анализ выделяет частицы, а не фон.
5. Выполнить регрессионный сценарий двухкамерного Actual Flow с AFXML и 16-битными кадрами.
6. Записать в acceptance.md команды, параметры, результаты, доступность реального набора и ограничения. Не помечать невыполненные проверки успешными.
7. При обнаружении дефекта исправлять только непосредственно связанную интеграцию; отдельную крупную проблему описать отдельно, не расширять задачу.

Не требовать доступа к пользовательскому Desktop для автоматической проверки. Не устанавливать новые библиотеки без необходимости; использовать зависимости проекта и временные каталоги.
