# Подставлять параметры config.json в интерфейс серии

Локальный ID: FS-10  
Метки для GitHub: enhancement, frame-sequence  
Зависимости: 02, 09  
Общий контракт: [README](README.md)

## Результат

Подставлять параметры config.json в интерфейс серии. Выполнить только этот шаг после его зависимостей.

## Файлы для изучения и изменения

- gui/automated_pipeline_tab.py

Допустимы небольшие целевые тесты в tests/. Иные изменения — только если непосредственно необходимы этому шагу; объяснить их в итоговом отчёте.

## План реализации

1. После успешного сканирования серии применить доступные SequenceMetadata: размеры → plane_width/plane_height, масштаб → scale_spin, dt → dt_spin, полярность → выбор частиц, глубина → выбор 8/16 бит.
2. Обеспечить точность полей: 0.00001 м/px и 0.0001 с должны сохраняться без округления до нуля.
3. Автоподстановку выполнять только при сканировании серии; после этого ручные изменения не перезаписывать при запуске или переключении других настроек. Если JSON отсутствует, оставить ручные значения.
4. Показать предупреждения сканера и кратко записать в лог подставленные параметры с единицами. Не включать преобразование координат автоматически.
5. Порог не выводить из JSON: показать, что он требует подбора. При изменении диапазона порога не оставлять недопустимое значение.
6. Обновить короткую инструкцию в README.md: выбор серии, проверка порога/площадей/фильтров, единицы масштаба и dt, отдельная папка результатов.

## Критерии приёмки

- [ ] Для предоставленной серии UI показывает 640×480, 8 бит, тёмные частицы, 0.00001 м/px и 0.0001 с.
- [ ] Ручная правка dt после сканирования сохраняется в конфигурации запуска.
- [ ] Без JSON серия доступна для ручной настройки; Actual Flow не получает настройки серии автоматически.

## Проверка

Проверить валидный/отсутствующий JSON, точность spinbox и сохранение ручных изменений; пройти инструкцию README.

Не требовать доступа к пользовательскому Desktop для автоматической проверки. Не устанавливать новые библиотеки без необходимости; использовать зависимости проекта и временные каталоги.
