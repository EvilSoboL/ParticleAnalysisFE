## Результат

Читать параметры серии из соседнего config.json. Выполнить только этот шаг после его зависимостей.

## Файлы для изучения и изменения

- src/data_processing/experiment_preprocess.py

Допустимы небольшие целевые тесты в tests/. Иные изменения — только если непосредственно необходимы этому шагу; объяснить их в итоговом отчёте.

## План реализации

1. Добавить dataclass SequenceMetadata с необязательными полями width_px, height_px, bit_depth, scale_m_per_px, dt_seconds, dark_particles. Добавить в конец ExperimentRecord поле sequence_metadata: Optional[SequenceMetadata] = None.
2. Для scan_frame_sequence читать только folder.parent/config.json. Схема: camera.width_px, height_px, bit_depth, scale_um_per_px, frame_interval_us; background.tone.
3. Преобразовать микрометры в метры и микросекунды в секунды множителем 1e-6. background.tone="light" означает dark_particles=True, "dark" — False, неизвестное значение — None.
4. Проверять типы, конечность и положительность чисел; размеры — целые, bit_depth только 8 или 16. Не принимать bool как число. Невалидное поле оставлять None и добавлять предупреждение.
5. Отсутствующий или повреждённый config.json не блокирует серию: предупреждение и ручные параметры. Не считать настройки JSON доказательством реального формата PNG.

## Критерии приёмки

- [ ] Для значений 640, 480, 8, 10 и 100 получаются 640×480, 8 бит, 0.00001 м/px и 0.0001 с.
- [ ] Отсутствие файла, неверный JSON и невалидное поле не приводят к исключению и не делают кадры неготовыми.
- [ ] Actual Flow не читает config.json.

## Проверка

Проверить валидный JSON, отсутствие файла, частично неверные значения и точность преобразования единиц.

Не требовать доступа к пользовательскому Desktop для автоматической проверки. Не устанавливать новые библиотеки без необходимости; использовать зависимости проекта и временные каталоги.
