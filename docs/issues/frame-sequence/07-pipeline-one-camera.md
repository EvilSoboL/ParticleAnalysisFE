## Результат

Провести серию через автоматический конвейер. Выполнить только этот шаг после его зависимостей.

## Файлы для изучения и изменения

- execute/full_pipeline.py

Допустимы небольшие целевые тесты в tests/. Иные изменения — только если непосредственно необходимы этому шагу; объяснить их в итоговом отчёте.

## План реализации

1. Добавить в конец AutomatedPipelineConfig input_mode="actual_flow", dark_particles=False; валидировать режим и совпадение input_mode всех выбранных ExperimentRecord с конфигурацией.
2. В _process_experiment передавать режим и полярность в SortBinarizeParameters. Для серии выбирать cameras=("cam_1",), для Actual Flow обе камеры и передавать в PTVParameters.
3. Строить source_files по выбранным камерам; не требовать CSV второй камеры для серии. Последующие фильтрация, усреднение и преобразование используют этот набор.
4. Убрать жёсткие 50% на камеру в прогрессе затронутых этапов: долю рассчитывать по количеству камер.
5. Сохранённая конфигурация должна включать режим/полярность; отчёт и result.files содержат только реальные результаты. Сохранить существующие форматы файлов.

## Критерии приёмки

- [ ] Серия проходит подготовку, PTV и выбранные этапы обработки без cam_2, если графики отключены.
- [ ] Параметры масштаба и dt доходят до преобразования без изменения единиц.
- [ ] Конфигурация с несовпадающим режимом записи отклоняется.
- [ ] Actual Flow продолжает обрабатывать обе камеры.

## Проверка

Синтетическая серия с известным смещением; небольшой запуск без графиков, с преобразованием и проверкой ожидаемой скорости. Порог/площади задать явно.

Не требовать доступа к пользовательскому Desktop для автоматической проверки. Не устанавливать новые библиотеки без необходимости; использовать зависимости проекта и временные каталоги.
