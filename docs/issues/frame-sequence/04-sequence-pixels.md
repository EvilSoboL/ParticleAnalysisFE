## План реализации

1. Добавить в конец аргументов SortAndBinarize dark_particles=False.
2. В режиме серии принимать одноканальные uint8 и uint16 без масштабирования яркости; проверять согласованность размеров и глубины всех кадров до записи результата. Цветные, повреждённые и смешанные изображения отклонять с указанием файла.
3. Порог проверять по фактической глубине: 0..255 или 0..65535. Структурные проверки серии обязательны даже при validate_format=False; существующий флаг строгой 16-битной проверки Actual Flow сохранить.
4. Для dark_particles=True маска: img < threshold → 255, иначе 0. Для False сохранить img >= threshold → 255. Медианный фильтр, если включён, применять до порога.
5. В затрагиваемом пути чтения/записи обеспечить работу с кириллицей Windows (например, np.fromfile + cv2.imdecode и cv2.imencode + tofile), сохранив разрядность. Не проводить рефакторинг других модулей.

## Критерии приёмки

- [ ] 8-битный кадр с тёмным объектом даёт белый объект на чёрном фоне.
- [ ] Граничное значение порога обрабатывается согласно указанным сравнениям.
- [ ] 16-битный Actual Flow со светлыми объектами даёт прежнюю маску.
- [ ] Кириллический путь читается и записывается; смешанные размеры/глубины отклоняются до создания частичного набора пар.

## Проверка

Проверить маски на маленьких массивах, uint8/uint16, неверный порог, повреждённый файл и кириллический временный каталог.

Не требовать доступа к пользовательскому Desktop для автоматической проверки. Не устанавливать новые библиотеки без необходимости; использовать зависимости проекта и временные каталоги.
