## Результат

Строить графики только для камер серии. Выполнить только этот шаг после его зависимостей.

## План реализации

1. В _create_graphs добавлять отдельную гистограмму камеры только при наличии её ключа в stage_sources["raw"].
2. Для серии histogram_combined строить по единственному набору cam_1 без дублирования наблюдений; имя all_cameras можно сохранить для совместимости.
3. Построение векторных графиков оставить по реально доступным stage_sources. Проверить отсутствие других безусловных обращений к cam_2 в графиках.
4. Не менять правила обработки пустых данных и общую систему визуализации в рамках этой задачи.

## Критерии приёмки

- [ ] При конфигурации по умолчанию, где histogram_cam2=True, серия не падает с KeyError.
- [ ] Гистограмма all_cameras для серии содержит столько же наблюдений, сколько cam_1.
- [ ] Для Actual Flow остаются две отдельные и одна общая гистограмма.
- [ ] PNG/CSV графиков серии создаются для выбранных этапов без фиктивных данных.

## Проверка

Тест источников графиков на маленьких CSV и один реальный экспорт PNG/CSV. Не сравнивать изображения побайтно.

Не требовать доступа к пользовательскому Desktop для автоматической проверки. Не устанавливать новые библиотеки без необходимости; использовать зависимости проекта и временные каталоги.
