## План реализации

1. Добавить в конец PTVParameters cameras: tuple[str, ...] = ("cam_1", "cam_2"). Разрешить только ("cam_1",) и ("cam_1", "cam_2") для текущего объёма.
2. Передать список камер в анализатор через совместимое расширение set_input_folder(folder_path, cameras=("cam_1", "cam_2")); хранить список в экземпляре.
3. Валидация и process_all должны требовать и обрабатывать только явно выбранные камеры. Не определять режим молча по отсутствию каталога.
4. Для одной камеры сохранить поля результата; cam2_pairs_count=0. Не создавать фиктивные результаты второй камеры.
5. Не менять detect_particles, match_particles, формат CSV и смысл существующих счётчиков.

## Критерии приёмки

- [ ] PTVParameters(cameras=("cam_1",)) работает без cam_2 и выдаёт cam_1_pairs_sum.csv.
- [ ] Вызов по умолчанию по-прежнему требует обе камеры.
- [ ] Нет обращения к отсутствующей cam_2 при обработке/отмене; существующие двухкамерные результаты совместимы.
