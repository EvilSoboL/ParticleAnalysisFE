# Добавить выбор серии и её параметры во вкладку конвейера

Локальный ID: FS-09  
Метки для GitHub: enhancement, frame-sequence  
Зависимости: 01, 07, 08  
Общий контракт: [README](README.md)

## Результат

Добавить выбор серии и её параметры во вкладку конвейера. Выполнить только этот шаг после его зависимостей.

## Файлы для изучения и изменения

- gui/automated_pipeline_tab.py

Допустимы небольшие целевые тесты в tests/. Иные изменения — только если непосредственно необходимы этому шагу; объяснить их в итоговом отчёте.

## План реализации

1. В существующей вкладке добавить QComboBox «Формат входных данных»: Actual Flow (actual_flow, по умолчанию) / Серия кадров — одна камера (frame_sequence).
2. В _scan вызвать нужный сканер. При смене режима или входного пути сбросить старые записи и запретить запуск до повторного сканирования. Учесть путь из диалога, который меняется через setText: одного textEdited недостаточно.
3. Добавить выбор полярности частиц. Для серии при первом выборе использовать тёмные частицы; Actual Flow по умолчанию светлые. Передавать input_mode и dark_particles в _build_config.
4. Для серии показать «Пары: 1–2, 3–4, …; без отражения». Не добавлять перекрывающиеся пары.
5. Для ручной настройки серии добавить выбор глубины 8/16 бит, управляющий диапазоном порога; начальный выбор 8 бит, порог 128 лишь стартовый, не оптимальный. Actual Flow сохраняет прежние значения 16 бит/2000. Выбор глубины — подсказка UI, backend проверяет реальные изображения.
6. Отключить настройки второй камеры для серии, histogram_cam2 передавать False; при возврате Actual Flow восстановить доступность. Заблокировать новые элементы при выполнении через существующий _set_running.
7. Не добавлять новый экран или новую систему предпросмотра.

## Критерии приёмки

- [ ] Папка frames отображается одной готовой записью без AFXML.
- [ ] Можно запустить серию с вручную заданными параметрами через существующий worker.
- [ ] Смена формата/пути не запускает старые записи; выбор папки через диалог также сбрасывает состояние.
- [ ] При обратном переключении доступны обычные настройки Actual Flow.

## Проверка

Ручной smoke-тест вкладки в обоих режимах; если окружение позволяет, небольшой Qt-тест сброса записей и _build_config. Не вводить новую зависимость ради GUI-тестов.

Не требовать доступа к пользовательскому Desktop для автоматической проверки. Не устанавливать новые библиотеки без необходимости; использовать зависимости проекта и временные каталоги.
